# Canvas MCP 0.5.3 — Telegram approvals and context

The Codex bot accepts **Yes/No** for simple confirmations, including MCP file downloads. No JSON is needed, and the response applies only to the displayed operation. With several requests pending, reply to the corresponding Telegram message or use its code. Forms with fields still require valid data; expired codes cannot approve another request.

New messages during execution steer the active request. The native Codex conversation is preserved alongside a private assignment reference. Current targets take priority over old work. Reply to a GitHub reminder or send its assignment link; an unquoted “this assignment” is resolved against current deadlines, asking when ambiguous.

Update the checkout and dependencies. With the receiver stopped and no active task, start it again to refresh the private macOS runtime. You do not need to delete conversations or replace Canvas/Telegram tokens.

Automatic mode remains an explicit choice. Normal permissions still apply, no global authorization is granted, and interrupted submissions are not replayed. Wheels/GHCR images provide MCP; the Telegram agent uses the source checkout.
