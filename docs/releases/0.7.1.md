# Canvas MCP 0.7.1 — Clearer Telegram summaries

Telegram reminders now use separate, numbered sections for assignment deadlines,
new or updated assignments, announcements, discussions, materials, and events.
Normal items stay together with their dates and links. Continued messages repeat
their category, and oversized fields are split within Telegram's UTF-16 limit
without breaking links.

- Shorten repetitive course labels, preserving full labels when shorter names
  would be ambiguous. Complete names remain in the private JSON snapshot.
- Show an assignment only in the deadline section when it also appears among
  the week's updates.
- Replace repeated technical errors with a short check-status summary, grouped
  by source and number of affected courses. Full sanitized diagnostics remain in
  the private snapshot; unavailable sources are still explicit.
- Explain weekly repetition in plain language and format dates in the selected
  language and report timezone.
- Add `CANVAS_NOTIFICATION_LANGUAGE=en|pt-BR`. English remains the default;
  use an Actions repository variable for cloud reminders or your private `.env`
  for local commands. Source course titles remain in their original language.
- Pace multipart delivery without automatically retrying uncertain sends.

The reminder schedule, weekly data window, Canvas queries, and 18 MCP tools are
unchanged. Formatting uses no models and does not consume AI tokens. Regression
tests use synthetic data and mocked HTTP; no real Telegram message is needed to
verify the format.
