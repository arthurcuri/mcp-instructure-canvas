# Canvas MCP 0.5.1

Canvas MCP combines local Canvas API access, optional Telegram deadline reminders, and an optional local Codex/Claude agent with guided account/mode selection.

This release adds GitHub Packages distribution, downloadable Python files, and archive checks. Local stdio use requires no hosted MCP server.

- MCP: 18 tools, a catalog of 1,118 REST operations, GraphQL, and file transfers.
- Reminders: GitHub Actions requesting 08:00 São Paulo, without model calls; dispatch can be delayed.
- Agent: `uv run canvas-agent setup`, subscription login, manual mode by default.
- Optional automatic worker: explicit local authorization and independent submission verification.
- Distribution: wheel, source, SHA256SUMS, and GHCR amd64/arm64 images.

See the [README](https://github.com/arthurcuri/mcp-instructure-canvas#readme), [package guide](https://github.com/arthurcuri/mcp-instructure-canvas/blob/main/docs/packages.md), and [validation record](https://github.com/arthurcuri/mcp-instructure-canvas/blob/main/docs/validation.md).

Live reads, reminder delivery, and an owner-requested Telegram → Codex → MCP → Canvas → Telegram query were verified. Writes and automatic submissions use mocked testing; no real coursework was submitted to test this release. Claude Telegram requires organization-enabled Channels. Automatic mode remains inactive until explicitly chosen.
