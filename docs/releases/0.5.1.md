Canvas MCP reúne **acesso ao Canvas**, **lembretes diários no Telegram** e
**um agente local Codex/Claude para atividades**, com escolha guiada de conta/modo.

Esta release acrescenta distribuição pelo GitHub Packages, arquivos Python para
download e verificações de empacotamento. O funcionamento local continua sem
exigir hospedagem de um servidor MCP.

- MCP: 18 ferramentas, catálogo de 1.118 operações REST, GraphQL e arquivos.
- Lembretes: GitHub Actions às 08h de São Paulo, sem modelo de IA.
- Agente: `uv run canvas-agent setup`, login pela assinatura, modo manual por padrão.
- Automático opcional: trabalhador local autorizado pelo `.env`; verifica entregas.
- Distribuição: wheel, fonte, SHA256SUMS e imagem amd64/arm64 no GHCR.

## Instalar

Para usar as três funcionalidades, siga o
[README](https://github.com/arthurcuri/mcp-instructure-canvas#readme) e execute o setup.
Os arquivos anexos também permitem instalar apenas o MCP por `pip`/`uv`.
O [guia de pacotes](https://github.com/arthurcuri/mcp-instructure-canvas/blob/main/docs/packages.md)
explica Docker, volumes, versões e checksums.

## Validação e limites

A consulta real ao Canvas, o lembrete pelo GitHub Actions e uma mensagem real
Telegram → Codex → MCP → Canvas → Telegram foram verificados. A mensagem consultou
todas as matérias nos próximos sete dias e o resultado coincidiu com o lembrete.
O [relatório de validação](https://github.com/arthurcuri/mcp-instructure-canvas/blob/main/docs/validation.md)
registra o escopo e os testes reproduzíveis.

Escritas e o trabalhador automático são testados com modelos/HTTP simulados;
nenhum trabalho real foi enviado para testar esta release. Claude Telegram exige
Channels habilitado pela organização; esse fluxo está sujeito à configuração do
administrador. O modo automático fica desativado até ser escolhido pelo usuário.
