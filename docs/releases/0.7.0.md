# Canvas MCP 0.7.0 — Weekly course updates in reminders

Scheduled reminders now include weekly course updates alongside assignment
deadlines, without model calls or Canvas writes.

## Weekly snapshot

- Published announcements.
- New forum topics and existing topics with new replies.
- Created or updated pages, files, and assignments, including undated assignments.
- Created or updated calendar events dated between Monday and the next seven days.

Updates cover Monday 00:00 through the snapshot time in `CANVAS_TIMEZONE`.
Deadlines retain their selected period, normally the next seven days. Daily runs
intentionally repeat that week's items. No delivery-deduplication state or course
data is stored in a public cache.

Summaries contain titles, local dates, and institution links. They do not copy
course bodies, individual replies, or signed storage URLs, and do not mark
anything as read. Drafts, future announcements, and inaccessible files are excluded.
Unavailable sources and undated items are reported explicitly; malformed dates
fail the run. Module rearrangements, grades, and external-tool activity are outside
this feature's coverage.

## Usage and compatibility

The daily/weekly Actions workflows and local scheduling wrapper request updates.
Direct CLI calls can opt in with:

```sh
uv run canvas-weekly-check --all-courses --include-updates --output .local/weekly-report.json
```

Add `--telegram` only when you intend to send to your configured chat. Existing
schedule enable variables, credentials, provider choice, and automatic-worker mode
are unchanged. Installation does not enable a schedule. The agent's internal
deadline lookup and the 18 MCP tools retain their existing behavior.

Regression coverage includes local week boundaries, publication cutoffs, new
replies in older discussions, pagination, inaccessible sources, private links,
Unicode message splitting, and the deadline-only CLI path.
