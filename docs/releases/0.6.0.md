# Canvas MCP 0.6.0 — English-first documentation and contribution workflow

English is now the default for the README, documentation, MCP instructions, CLI
help, diagnostics, and built-in Telegram messages. A separate Brazilian Portuguese
README remains available, and agents answer in the owner's language. Original
Canvas content is preserved.

## Changes

- Add setup, API, reminder, agent, and package guides, plus contributing
  instructions, issue forms, a pull request template, a code of conduct, and a roadmap.
- Add English assignment references and `[[file: ...]]` attachments to the
  Telegram bridge. Portuguese approval replies and `[[arquivo: ...]]` still work.
- Fix MCP verification for installations without a default course; accept
  `--course-id` and report skipped course checks when there are no active courses.
- Update security documentation for implemented agents and explicit automatic
  authorization. Installation does not activate schedules or automatic submissions.

## Configuration and migration

- New `.env.example` copies use a fictitious Canvas origin, `UTC`, and
  `CANVAS_READ_ONLY=true`. Set your institution URL, token, and preferred timezone.
  Enable writes deliberately when you need them.
- Existing private `.env` files and runtime defaults are unchanged. Keep existing
  client registrations, including the legacy `canvas-pucminas` label.
- Cloud reminders now require the `CANVAS_API_URL` repository variable; they no
  longer default a fork's token to the maintainer's institution.
- Built-in messages are in English, and reminder dates use `YYYY-MM-DD at HH:MM`.
  Scripts that parse human-readable text should use structured results instead.
- Update the checkout and run `uv sync --locked`. To update an installed agent
  runtime, stop it when idle and explicitly start it again. Conversations and
  coursework files are preserved; no login or service restart is automatic.

## Validation

All 202 mocked tests, lint, formatting, shell syntax, distribution build, and
archive checks passed for the English-first implementation. Read-only stdio
verification against the configured Canvas account passed with 18 tools and
course, assignment, deadline, module, and page queries. Canvas writes, Telegram
delivery, and agent execution were covered by mocked tests. See the
[validation record](https://github.com/arthurcuri/mcp-instructure-canvas/blob/main/docs/validation.md).

Release artifacts include a wheel, source archive, SHA256SUMS, and Linux
amd64/arm64 images at `ghcr.io/arthurcuri/mcp-instructure-canvas:v0.6.0`.
