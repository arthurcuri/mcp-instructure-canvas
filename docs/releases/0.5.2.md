O MCP agora anuncia **a versão do projeto** no handshake, e a imagem multiarch
preserva descrição, licença e origem no GitHub Packages.

Na validação dos arquivos publicados, o handshake anunciava a versão do SDK
e o índice Docker descartava as anotações de apresentação. Esta correção usa
a versão do Canvas MCP na inicialização e exporta os manifests como OCI.
O workflow verifica ambos antes de publicar a release.

As três funcionalidades continuam disponíveis:

- MCP Canvas: leitura/escrita, catálogo REST, GraphQL e transferência de arquivos.
- Lembretes Telegram: GitHub Actions às 08h de São Paulo, sem IA.
- Agente Codex/Claude: setup guiado, assinatura do CLI e modo automático opcional.

**Verificado ao vivo:** Canvas pelo MCP local e Docker, lembrete no GitHub Actions,
mensagem real Telegram → Codex → MCP → Canvas → Telegram, com resposta final
confirmada pelo usuário. **Simulado:** entregas e trabalhador automático, sem
modificar atividades reais. Claude Telegram depende da política Channels do Team.

Arquivos anexos: wheel, fonte e SHA256SUMS. Imagem pública:
`ghcr.io/arthurcuri/mcp-instructure-canvas:v0.5.2`, para Linux amd64/arm64.
