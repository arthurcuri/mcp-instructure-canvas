# Canvas MCP 0.5.2

The MCP handshake now reports the project version, and the multiarchitecture image preserves description, license, and source metadata in GitHub Packages.

Published-package validation found that the handshake reported the SDK version and the Docker index lost its annotations. This fix sets the Canvas MCP initialization version and exports OCI manifests. The workflow verifies both before creating the release.

Canvas reads/writes, REST discovery, GraphQL, transfers, optional Telegram reminders, and guided Codex/Claude setup remain available. Automatic mode is opt-in.

Live checks covered local/Docker Canvas reads, reminder delivery, and a real owner-requested Telegram query with confirmed final reply. Submissions and automatic work were mocked. Claude Telegram remains subject to organization Channels policy. Requested reminder times do not guarantee punctual dispatch.

Assets: wheel, source, SHA256SUMS. Image: `ghcr.io/arthurcuri/mcp-instructure-canvas:v0.5.2` for Linux amd64/arm64.
