# Canvas MCP 0.7.2 — Focused Telegram reminders

Telegram reminders now show only assignment deadlines and weekly announcements
by default. New/updated assignments, materials, discussions, calendar events and
check-status messages are omitted, including the inline undated-assignment count.

Use `CANVAS_NOTIFICATION_SECTIONS` to select categories in a private `.env` for
local delivery or an Actions repository variable for cloud reminders:

```dotenv
CANVAS_NOTIFICATION_SECTIONS=deadlines,announcements
```

Supported categories are `deadlines`, `assignments`, `announcements`, `discussions`,
`materials`, `events`, and `status`. Use `all` to restore the complete notification
format. Language selection, dates, links, message packing and delivery pacing keep
their existing behavior.

This is a display selection. Private JSON snapshots retain the complete collected
updates, unavailable-source diagnostics and completeness flags. Scheduled logs
continue to report source-error counts. No Canvas writes, model calls or new
schedule activation are introduced.
